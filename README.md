# Mi Primera Aplicación

A simple Python application.

Incluye **Mi Escritorio Remoto**: controla tu PC desde el celular.
Ver [remote_desktop/README.md](remote_desktop/README.md).

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

## Test

```bash
pytest tests/
```

## Lint

```bash
flake8
```
